# Tested FusionAI image workflows

These examples reuse actual FusionAI workspace tests. They include reference and result images, original prompts, observed settings and review criteria. The examples were not generated by the repository's CLI or CI. API reproduction instructions require an available model from your own catalog.

| Example | Primary task | Guide |
| --- | --- | --- |
| Clothing + model | Compose a garment reference with a model reference | [Fashion product photography](fashion-product-photography/README.md) |
| Backpack + scene | Change the product setting using a second reference | [Product background replacement](product-background-replacement/README.md) |
| Headphones | Remove one distracting prop and restore the tabletop | [Object removal](object-removal/README.md) |

Generated product images still need inspection: a plausible result can change a zipper, seam, label or attachment. See [media attribution](../docs/MEDIA.md).
